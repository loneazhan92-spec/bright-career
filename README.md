# Bright Career Secondary School Website

Static website for GitHub Pages.

## Files
- index.html
- style.css
- script.js
- assets/ (uploaded school photos and student-group logo)

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder (keep the `assets` folder).
3. Go to Settings → Pages.
4. Select the `main` branch and `/ (root)`.
5. Save and open the GitHub Pages URL.

The admission form is a front-end demo. To receive real submissions, connect it to a form service/backend.
